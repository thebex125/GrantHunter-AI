## 🚀 Overview

**GrantHunter AI** is an autonomous multi-agent intelligence platform that turns the daunting friction of grant hunting, eligibility calculation, and proposal drafting into an effortless 120-second workflow.

Instead of generic chatbot queries, GrantHunter orchestrates a **4-Specialized Autonomous Swarm**:
1. **Agent 1 (The Scout):** Ingests and normalizes live opportunity feeds across **DoraHacks, Gitcoin, Arbitrum Foundation, Optimism RetroPGF, and Solana Superteam**.
2. **Agent 2 (The Matcher):** Evaluates user project tech stacks, calculating predictive **Fit Scores (0–100%)** and win probability vectors.
3. **Agent 3 (The Proposal Architect):** Generates end-to-end, institution-grade grant proposals (Executive Summary, Technical Architecture, Milestones & Verifiable Deliverables, and Granular Budget Allocations).
4. **Agent 4 (The Jury Critic / Red Team):** Benchmarks drafts against official DoraHacks rubrics, identifies weaknesses, and auto-refines copy for Grade A+ submissions.

## 🎨 World-Class, Anti-"AI Slop" Design

Designed with the aesthetic precision of modern developer tools (**Linear, Raycast, Manus.im, and 21st.dev**):
* **Constellation Sonar Radar:** Interactive canvas with real-time rotating sweep line, concentric distance bands, and orbiting grant satellite nodes.
* **Transparent Swarm Stream:** Terminal drawer exposing live agent reasoning logs.
* **Side-by-Side Proposal Studio:** Split-pane proposal viewer with real-time audit scorecards, 1-click Markdown export, and direct DoraHacks BUIDL submission links.

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
